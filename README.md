# Student Management System 🎓

A console-based Student Management System developed using C++.

## 📌 About The Project

This project is designed to manage student records and their enrolled courses through an interactive menu-driven application.

Users can add and delete students, manage their courses, and display all registered students.

## ✨ Features

### 👨‍🎓 Student Management
- Add new students.
- Delete existing students.
- Display all registered students.
- Check whether a student exists before performing operations.

### 📚 Course Management
- Add courses to a specific student.
- Delete courses from a specific student.
- Display each student's enrolled courses.
- Check whether a course exists before deleting it.

## 🚀 How To Run

1. Download the repository.
2. Open the `.cpp` file using Code::Blocks or another C++ IDE.
3. Compile and run the program.
4. Choose an option from the main menu.

**Note:** This project uses `windows.h` for colored console output, so it is designed for Windows.
